# Web Services with Spring Boot and JPA / Hibernate

A RESTful web services project built with Spring Boot and JPA/Hibernate, organized in logical layers and using an H2 in-memory database for testing.

## Objectives

- Create a Spring Boot Java project
- Implement the domain model
- Structure the logical layers: resource, service, repository
- Configure the test database (H2)
- Seed the database
- Implement CRUD operations (Create, Retrieve, Update, Delete)
- Handle exceptions
